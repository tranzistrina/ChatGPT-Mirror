# Предварительный аудит dairoot/ChatGPT-Mirror

Исходник: dairoot/ChatGPT-Mirror commit 8c3a24093f8c7b4c72a4ab39fc94afe9f3aacbf7 (проект больше не поддерживается). Это **статический аудит**, не динамический пентест. Доказать безопасность закрытых Docker-образов gateway/cf5s невозможно без кода или воспроизводимого анализа бинарников.

## Архитектура
Vue (frontend) -> Django REST API (backend, SQLite) -> внешний chatgpt-gateway, обслуживающий чат и авторизацию. Caddy направляет /admin/* к Vue, /0x/* к Django, остальное к gateway. SQLite хранит чувствительные access/session/refresh tokens.

## Подтверждённые риски
- **Критический:** фиксированный Django SECRET_KEY в backend/app/settings.py.
- **Высокий:** IDOR в GET /0x/user/get-mirror-token, где любой вошедший пользователь мог запросить чужой user_id без проверки владельца.
- **Высокий:** ChatgptAccount.get_by_gptcar_list возвращал все аккаунты, когда список закреплённых пулов пуст.
- **Высокий:** настройки local с DEBUG=True и стандартным паролем dairoot/dairoot включались при отсутствии DJANGO_ENV.
- **Высокий:** docker-compose использует mutable :latest образы и Watchtower с доступом к /var/run/docker.sock.
- **Высокий:** gateway/cf5s имеют закрытую реализацию: обработка секретов, сообщений и исходящих соединений не проверена.
- **Высокий:** токены OpenAI/ChatGPT сохраняются в SQLite открытым текстом.
- **Средний:** ALLOWED_HOSTS=["*"], потенциально подделываемый X-Forwarded-For и запросы без timeout.
- **Средний:** frontend использовал v-html для cfg.notice, что опасно при получении недоверенного HTML.
- **Средний:** дата истечения пользовательского аккаунта проверялась при login, а существующие DRF Token могли продолжать работать.
- **Накопленные зависимости:** Django==5.1.1, Vue/Vite и другие версии устарели и требуют security-upgrade после тестов.

## Патчи этого форка
Смена SECRET_KEY/host-конфигурации на переменные окружения; production по умолчанию; снятие локальных статических паролей; проверка полномочий в GetMirrorToken; исправление пустого списка пулов; отказ от v-html; проверка срока аккаунтов; timeout для gateway; локализация открытой панели RU/EN и переключатель языка.

## Что остаётся непроверенным
Gateway/cf5s; сетевые вызовы и возможная утечка в бинарных образах; внешняя API-совместимость; поведение современного ChatGPT; поддержка жизненного цикла всех токенов; полноценная проверка фронтенда; регрессионные тесты и dependency audit. В качестве публичного сервиса без этих работ проект **не рекомендован**.
